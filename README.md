# LIMINAL

**A dark UI engine, not a component collection.**

---

موتور رابط کاربری تیره — ساخته‌شده روی یک پایهٔ ادراکی.

هر سطح، مرز، سایه، ریم، اندازه و حرف در این سیستم از **اندازه‌گیری** می‌آید:
از اینکه چشم واقعاً چه چیزی را می‌تواند تفکیک کند. نه از سلیقه، و نه از
پالتی که کسی دوست داشته.

---

## ریپو از کجا شروع می‌شود

**قانون** در [`LIMINAL-POLICY.md`](./LIMINAL-POLICY.md) است و **ریشه** است.
موتور از قانون ساخته می‌شود، نه برعکس. کامپوننت‌ها از قانون و موتور تولید می‌شوند.

```
LIMINAL-POLICY.md   ← قانون (ریشه)
engine/             ← از قانون ساخته می‌شود
components/         ← از قانون و موتور تولید می‌شود
```

## وضعیت

این ریپو تازه شروع شده است.

| چه چیزی | وضعیت |
|---|---|
| سیاست | در حال نوشتن |
| موتور | ساخته نشده |
| کامپوننت | ساخته نشده |

هیچ عددی در سیاست نمی‌نشیند مگر اینکه اندازه‌گیری شده باشد.
